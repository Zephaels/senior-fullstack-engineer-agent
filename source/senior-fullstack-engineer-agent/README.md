# Senior Full-Stack Engineer AI Agent

**Version 1.0.0-rc.4.8 - RC Qualification Candidate**

A risk-adaptive, inquiry-driven software-engineering Agent Skill and Codex Plugin.
It turns ambiguous ideas or existing codebases into evidence-backed product, architecture,
implementation, testing, security, release, and handoff outcomes.

## Release status

This package is feature-complete for the 1.0 lifecycle but is intentionally labelled an RC.
It must pass the included real Codex installation, discovery, RED -> GREEN -> Regression,
pressure, Brownfield, autonomy-safety, and release qualification plan before a `v1.0.0`
GA tag is created.

## Core capabilities

- Product discovery and one-question-at-a-time intent clarification
- Greenfield and Brownfield flows
- Repository discovery and blast-radius analysis
- Requirements, architecture, API/data, and cross-platform UX design
- Vertical-slice planning and incremental implementation
- TDD, systematic debugging, QA, and dual-axis code review
- Threat modeling, security verification, preflight, release, rollback, and handoff
- Trigger, behavior, pressure, and regression evaluation
- Bounded unattended execution with exact preauthorization, default-dry-run supervision,
  durable redacted evidence, hard stops, health gates, and preauthorized rollback

## Test this RC

1. Read `CODEX_TEST_INSTRUCTIONS.md`.

3. Require Codex to follow `docs/CODEX_RC_TEST_PLAN.md`.
4. Preserve all evidence under `qualification-results/`.
5. Do not rename or tag the package as GA unless every mandatory gate passes.
