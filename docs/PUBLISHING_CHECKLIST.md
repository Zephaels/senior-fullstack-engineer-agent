# Publishing Checklist

- [ ] Version is strict semver and differs from the last distributed content.
- [ ] Source validation passes.
- [ ] Plugin validation passes.
- [ ] Marketplace validation passes.
- [ ] Archives build twice with identical hashes.
- [ ] Checksums and SPDX SBOM exist.
- [ ] License and NOTICE are reviewed.
- [ ] SECURITY and support path are finalized.
- [ ] Public homepage/repository/privacy/terms URLs exist before adding them to the manifest.
- [ ] Real Codex installation and Skill discovery pass.
- [ ] RED → GREEN → Regression model evaluation passes on the release version.
- [ ] Known issues and accepted risks are approved.
- [ ] Release notes match the packaged content.
- [ ] Optional artifact attestation is generated and verified when enabled.
