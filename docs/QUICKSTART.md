# Quick Start

## ChatGPT
Upload `Senior-FullStack-Engineer-Agent-v1.0.0-GA-ChatGPT-Skill.zip` from Plugins → Skills → Create → Upload from your computer.

## Codex Plugin
Extract the plugin into `~/plugins/senior-fullstack-engineer-agent/` and add the marketplace entry from `.agents/plugins/marketplace.json` to the applicable personal or repository marketplace. Start a new Codex thread or force reload skills after installation.

## First test

Use senior-fullstack-engineer-agent. I want to build an AI video generation platform. Do not write code yet. Classify the task, state what can be learned from current context, and ask only the highest-value unresolved question.
