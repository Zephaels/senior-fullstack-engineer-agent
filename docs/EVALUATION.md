# Evaluation

The evaluation program has four layers:

1. Trigger and negative-trigger routing.
2. Behavior expectations.
3. Pressure resistance.
4. Cross-Skill regression.

Real model comparison uses:

- RED: no target Skill instructions.
- GREEN: core governance plus target Skill.
- Regression: full Skill tree.

A mock runner may validate transport, schemas, and orchestration. It must never be used as a model quality score.
